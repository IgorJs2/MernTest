# MernTest — URL Shortener (MERN practice)

> [!WARNING]
> **DEPRECATED — OLD LEARNING PROJECT (2021).** Archived and no longer maintained. Kept public to show my early progress.
> For my current production work see [my GitHub profile](https://github.com/IgorJs2) — Metrocraft 2036 and Stalcraft LAB.

My first full-stack Node.js project: a link shortener with user accounts.

## Features
- Registration and login with JWT and bcrypt, request validation
- Create short links (shortid) and redirect to the original URL
- Click counter per link

## Tech stack
Node.js, Express, MongoDB, Mongoose, JWT, express-validator
